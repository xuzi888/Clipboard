## ✨ 核心特性

- **🕒 剪贴板历史监听**：后台自动静默记录 Windows 剪贴板的文本和图片，支持自定义历史保留天数，告别重复复制。
- **🚀 拖拽与一键复制**：
  - **点击使用**：左键点击任意记录/短语即可复制到系统剪贴板。
  - **拖拽使用**：支持将文本、图片甚至文件直接拖拽到微信、Word 等第三方软件中。
- **🗂️ 三级快捷短语库**：支持 `场景 -> 分组 -> 短语` 的多层级管理，分门别类存储常用话术、代码片段。
- **🎬 全媒体格式支持**：除了纯文本，还完美支持图片预览、**视频缩略图预览 (基于 OpenCV)** 以及自定义短语备注。
- **⌨️ 全局快捷键唤出**：支持自定义全局呼出热键（默认 `Alt+V`），任何界面下瞬间唤出悬浮面板。
- **🎨 现代化 UI 体验**：
  - 支持 **深色模式 (Dark Mode)** / **浅色模式** 无缝切换及跟随系统。
  - 无边框悬浮窗设计，附带平滑动画、高斯模糊阴影、Toast 提示及 SVG 矢量图标。
- **💾 数据持久化与迁移**：纯本地 JSON 存储，支持数据的一键导入与导出，换电脑也能轻松带走你的话术库。
- **🛡️ 安全卸载体验**：卸载时提供贴心的数据保留选项，可自由选择“彻底清空数据”或“保留数据以便下次使用”，防止心血数据误删。
- **🚀 开机自启**：支持设置开机静默启动，随时待命。

## ⚙️ 快速开始

### 1. 环境准备

确保您的电脑已安装 **Python 3.8** 或更高版本。建议使用虚拟环境运行：

```bash
# 克隆/进入项目目录
cd clipboard_manager

# 创建并激活虚拟环境 (可选但推荐)
python -m venv venv
venv\Scripts\activate
```

### 2. 安装依赖

项目使用 PyQt6 作为界面框架，keyboard 监听全局快捷键，opencv-python 处理视频缩略图：

```bash
pip install -r requirements.txt
```

### 3. 启动程序

直接运行主入口文件即可启动程序：

```bash
python main.py
```

> **💡 提示**：
> 启动后，程序会自动隐藏到右下角的 **系统托盘** 中。
> 按下全局快捷键（默认 `Alt+V`）即可呼出主界面。右键点击托盘图标可进入“偏好设置”或退出程序。

## 💻 系统兼容性说明

本程序基于现代化的 Python 3.8+ 与 PyQt6 框架开发，以保证最佳的 UI 体验与性能。

- **支持的操作系统**：
  - **Windows 10 / Windows 11**：完美兼容，推荐使用。
  - **Windows 8 / 8.1**：基本支持，但部分现代 UI 特性（如阴影、圆角）可能会降级显示。
- **系统架构**：
  - **仅支持 64 位 (x64) 系统**。
  - **为什么不支持 32 位 (x86)？**
    1. **框架限制**：PyQt6 官方已逐渐放弃对 32 位系统的全面支持和测试。
    2. **性能与内存**：剪贴板管理（尤其是图片和视频缩略图缓存）需要较大的内存开销，32 位系统单进程 2GB 的内存限制容易导致程序崩溃。
    3. **主流趋势**：近十年的 Windows 电脑已全面普及 64 位架构，抛弃 32 位包袱可以让软件运行更轻量、更稳定。

## 📦 打包与发布

如果您希望将源码打包成独立的 `.exe` 可执行文件或制作成标准的 Windows 安装包，请按以下步骤操作。

### 1. 自动化一键打包 (推荐)

我们在项目中提供了一个自动化的打包脚本 `build_pack.py`，它不仅会自动调用 PyInstaller，还会：
1. **自动同步版本号**：从 `main.py` 同步最新版本号到打包脚本中。
2. **智能处理本地数据与设置**：打包时自动清空您的私人剪贴板历史（仅保留快捷短语结构）并重置偏好设置为默认状态，打包完成后自动恢复您的所有私人数据与设置，彻底避免隐私泄露。
3. **自动生成安装包**：在生成免安装绿色版后，会自动调用 Inno Setup 编译器生成 `.exe` 标准安装程序。

请在激活了虚拟环境的终端中运行：

```bash
# 确保在项目根目录，并激活虚拟环境
cd clipboard_manager
venv\Scripts\activate

# 执行一键全自动打包脚本
python build_pack.py
```
*编译完成后，绿色免安装版和最终的安装包 `.exe` 都将生成在 `dist/` 目录下。*

### 2. 制作标准安装包 (Inno Setup)

如果您希望制作带有“下一步”安装向导的纯中文标准安装包 (`.exe`)，可以借助 Inno Setup：

1. 下载并安装 [Inno Setup 6](https://jrsoftware.org/isdl.php)。
2. 项目中已内置了安装配置脚本 `setup_script.iss` 和中文语言包 `ChineseSimplified.isl`。
3. 在 Inno Setup 中打开 `setup_script.iss` 文件，点击顶部的 **Compile (编译)** 按钮。
4. 编译成功后，将在 `dist` 目录下生成 `剪贴板管理器安装程序.exe`，这即是最终的安装包，支持自动创建桌面快捷方式及卸载功能。

## 📖 使用教程

### 一、 剪贴板历史管理
1. **自动记录**：程序在后台静默运行。当您使用 `Ctrl+C` 复制文本或图片时，内容会自动留存。
2. **呼出面板**：按下 `Alt+V` 呼出主界面，在右侧列表中即可看到历史记录。
3. **快速粘贴**：点击卡片可重新复制；按住卡片可直接拖拽内容至目标输入框。
4. **清理记录**：悬浮在卡片上可点击右侧垃圾桶图标删除单条记录，或在设置中一键清空。

### 二、 快捷短语管理
1. **进入模块**：点击主面板左侧栏的 **“文件夹”图标** 切换至快捷短语管理界面。
2. **构建知识库**：
   - 点击左上角的 `场景` 按钮创建大分类（如：前端代码、售后客服）。
   - 在场景下点击 `分组` 按钮创建子分类（如：React组件、退机话术）。
3. **添加内容**：
   - 点击右上角 `新建短语` 按钮，支持输入纯文本。
   - 点击 `选择文件/图片`，可以添加本地媒体或文件，并为文件添加**文字备注**。
4. **快速检索**：在上方搜索框支持全局或按场景/分组过滤，快速定位所需短语。

### 三、 偏好设置
点击主面板左下角的 **“齿轮”图标** 进入设置页面：
- **外观主题**：手动切换深浅色或跟随系统。
- **全局快捷键**：点击输入框，直接按下您习惯的组合键（如 `Ctrl+Shift+C`）进行修改。
- **历史保留策略**：自定义保留天数，过期自动清理历史图片缓存。
- **数据导入/导出**：重装系统前可将短语数据导出为 JSON 文件，后续一键导入恢复。

### 四、 常见问题 (FAQ)
**Q: 为什么按下全局快捷键 `Alt+V` 无法唤出界面？**
A: 请检查是否有其他软件（如 QQ、微信或输入法）占用了此快捷键。您可以右键托盘图标进入“偏好设置”，修改为您习惯的其他组合键（如 `Ctrl+Shift+C`）。

**Q: 杀毒软件或 Windows Defender 提示风险或报毒？**
A: 这是因为程序使用了 `keyboard` 模块进行全局快捷键监听，且由 PyInstaller 打包，部分杀毒软件可能会产生误报。本项目完全开源，您可以自行检查源码，或将程序添加至白名单中放心使用。

**Q: 如何彻底退出程序？**
A: 为保证剪贴板监听不中断，点击主界面右上角的关闭按钮默认会隐藏到系统托盘。如需彻底退出，请在右下角系统托盘找到本程序的图标，右键选择“退出”。

**Q: 复制的图片为什么有时候无法显示？**
A: 本程序支持绝大多数标准系统剪贴板图片格式。但部分第三方软件（如某些截图工具或游戏内截图）可能使用了私有格式写入剪贴板，导致无法读取。

## 👨‍💻 二次开发指南

如果您希望在现有代码基础上进行二次开发或增加新功能，可以参考以下开发指引：

### 1. 核心技术栈
- **UI 界面开发**：基于 `PyQt6`，涵盖无边框悬浮窗、系统托盘图标以及树形控件交互。
- **全局快捷键**：使用 `keyboard` 模块，通过底层系统钩子实现跨软件热键监听。

- **数据存储**：轻量化架构，所有数据依赖本地 JSON 文件进行持久化读写。

- **`snippets_ui.py`**：核心视图层，负责渲染快捷短语面板的树形导航栏、右侧媒体卡片列表及拖拽事件 (`Drag & Drop`) 处理。

- 开发时，建议通过终端运行 `python main.py` 启动，程序的报错及部分状态提示会直接输出到终端控制台，便于定位问题。
- 若需调整 UI 样式，可重点关注代码中的 `setStyleSheet()` 样式表逻辑以及深浅色模式的动态切换逻辑。

**Q: 程序的数据和图片缓存存储在哪里？如何备份或迁移？**

**Q: 运行 `main.py` 时提示 `ModuleNotFoundError` (如 PyQt6、keyboard 等缺失)？**
A: 请确保您已经激活了虚拟环境（如果使用了 `venv`），并且正确执行了 `pip install -r requirements.txt` 安装所有必需的依赖。

**Q: 使用 PyInstaller 打包后，运行 `.exe` 闪退或报错找不到文件？**
A: 程序在运行时需要依赖外部静态资源（如 `images` 文件夹、`.json` 配置文件等）。请确保打包时按文档说明加入了 `--add-data` 参数，或直接使用项目中已配置好的 `.spec` 文件进行打包。

**Q: 开发时，OpenCV (`cv2`) 处理视频缩略图报错 `ImportError: DLL load failed`？**
A: 这通常是因为 Windows 系统缺失必要的 C++ 运行库。请尝试安装最新的 Microsoft Visual C++ Redistributable，若您使用的是 Windows 10/11 N 版本，还需要在系统中安装 Media Feature Pack。

**Q: `main.py` 中的 `APP_NAME` 和 `APP_ID` 变量有什么作用？**
A: 这两个变量是程序的核心标识：
- **`APP_NAME`** (如 `"KJJ 快捷剪贴板"`)：用于界面显示的软件名称，比如系统托盘的悬浮提示文本、关于页面的标题等。
  - 💡 **自动同步**：每次运行打包脚本 `build_pack.py` 时，该名称会被自动同步到安装包配置 (`setup_script.iss`) 和编译配置 (`ClipboardManager.spec`) 中，无需手动修改多个文件。
- **`APP_ID`** (如 `"KjjClipboardManager"`)：程序的全局唯一标识符，主要有三个核心用途：
  1. **开机自启动**：作为 Windows 注册表项的名称，用于在注册表 `Run` 路径下标记和管理程序的自启动命令。
  2. **防止程序多开**：程序启动时会利用该 ID 创建一个本地服务 (`QLocalServer`)。如果检测到已有相同 ID 的实例在运行，则会唤醒旧实例并退出当前程序。

A: 软件的核心版本号定义在 `clipboard_manager/main.py` 中（`APP_VERSION` 变量）。
